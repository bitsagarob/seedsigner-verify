**To Build:**
```
git clone https://github.com/3rdIteration/seedsigner-os/
cd seedsigner-os
git checkout SeSi-0.8.7+ShSi-B11
git submodule init
git submodule update
SS_ARGS="--all --app-repo=https://github.com/3rdIteration/seedsigner --app-branch=SeSi-0.8.7+ShSi-B11 --smartcard" docker compose up --force-recreate --build
```

**Note on Reproducibility:**
This is the first non-dev release for Lafrite and Luckfox Pico devices and there are still a few things with these two platforms that need to be tweaked for full reproducibility. (Probably for next release) Pi versions are reproducible as normal.

**To Build:**
```
git clone https://github.com/3rdIteration/seedsigner-os/
cd seedsigner-os
git checkout SeSi-0.8.7+ShSi-B12
git submodule init
git submodule update
SS_ARGS="--all --app-repo=https://github.com/3rdIteration/seedsigner --app-branch=SeSi-0.8.7+ShSi-B12 --smartcard" docker compose up --force-recreate --build
```
